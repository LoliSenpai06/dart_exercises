# Week 7: Dart Fundamentals – Variables, Data Types, Operators & I/O

A simple Dart console program demonstrating core programming constructs as part of the Mobile Development coursework.

## Project Overview
This project fulfills the Week 7 formative task by implementing:
- **Core Data Types:** `int`, `double`, `String`, and `bool`.
- **Arithmetic Operators:** Addition (`+`), Modulus (`%`), and Integer Division (`~/`).
- **Comparison Operators:** Greater than (`>`) and Equality (`==`).
- **Console I/O:** Output generated via `print()` using string interpolation.

## Files Included
- `main.dart` — The main executable Dart source code.
- `output.txt` — Captured console execution output.
- `README.md` — Project documentation.
